# Portfolio project entry

**Title:** Still — Personal Finance Dashboard

**Stack:** Java, Spring Boot, Spring Security, SQL, PostgreSQL, JavaScript, HTML, CSS, JUnit

**Description:** A full-stack personal finance app with account registration, session-based login, transaction tracking, monthly budgets, and visual spending reports. The responsive dashboard uses a warm glass-style design and connects to a validated REST API.

**Highlights:** Private data per account; BCrypt password hashing; CSRF protection; transaction and budget CRUD; monthly summaries; charts; CSV exports; SQL migrations and indexes; automated integration tests.

**Repository:** https://github.com/Shahran-Islam/Personal_Finance_Dashboard

**Demo sequence:** Register an account, load a fictional month, explore the overview, add and edit a transaction, set a category budget, export a report, and sign out.

**Possible resume wording after reviewing and running the project:**

- Developed a full-stack personal finance dashboard with Java, Spring Boot, SQL, and vanilla JavaScript, supporting transactions, monthly budgets, and visual reports.
- Implemented session-based authentication, BCrypt password hashing, CSRF protection, and user-scoped queries to isolate financial records.
- Added integration tests for CRUD, financial calculations, authentication, and cross-account access controls; supplied a Postman collection and Docker configuration.
