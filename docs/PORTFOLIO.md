# Portfolio project entry

**Title:** Personal Finance Dashboard API

**Stack:** Java · Spring Boot · SQL · PostgreSQL · JUnit · Postman

**Description:** A REST API for tracking income and expenses, setting monthly category budgets, and calculating financial summaries. The backend uses a Controller–Service–Repository structure, server-side validation, and a normalized SQL schema.

**Highlights:** Transaction and budget CRUD; monthly income, expense, and balance calculations; budget progress; indexed date filters; consistent HTTP errors; automated integration tests.

**Demo sequence:** List categories, add income and expenses, set a grocery budget, inspect the monthly summary, update a transaction, and show validation rejecting a negative amount.
